# WolfNex Technologies

Technology & Project Development Studio

Official website for **WolfNex Technologies** providing Academic Projects, Documentation, PPT & Journal Papers, Website Development, UI/UX Design, App Development, and Drone Softwares & Components.

## 🚀 Getting Started

### Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```

## ⚙️ Configuration
- Contact info, WhatsApp number, and direct hotline can be configured in `src/config.js`.
- Services, pricing plans, FAQs, and testimonials are managed in `src/data.js`.
- SPA routing for deployment is pre-configured via `vercel.json`.
